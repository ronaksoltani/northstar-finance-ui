# Project plan: northstar

## Brief

**Type:** Website design

**Problem:** Personal finance dashboards can overwhelm people with alerts and unexplained figures.

**Audience:** A user reviewing a sample monthly budget overview.

## Experience flow

1. Arrive at a direct, descriptive introduction.
2. Review the sample interface and its scope before interacting.
3. Try the core control: Change chart period and mask sample balances.
4. See a local result or demonstration state without sending a request to a service.

## Interaction

Period selection changes the illustrative chart; a control hides or reveals sample balances.

## Key design decision

Pair a calm visual hierarchy with visible context and privacy-minded balance masking.

## Boundaries

All balances, transactions and categories are fictional. This is not financial advice or a live account.

All named businesses, people, products, schedules, prices and quantitative values are fictional portfolio content. Replace them only with verified, permissioned material.

## Next iteration

Add transparent calculation notes, currency localization and privacy review before connecting real data.

## Learning goals

- Structure a complete page with meaningful headings, landmarks and labelled controls.
- Separate visual rules in CSS from interaction logic in JavaScript.
- Make states understandable with keyboard controls and live status text.
- Document assumptions and the boundary between a helpful prototype and a production service.
